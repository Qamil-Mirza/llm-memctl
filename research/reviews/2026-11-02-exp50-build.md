## Required fixes

1. **Same-outcome control (ruling on choice 9; overruled).** The control's recipient must be the same row that the arm patches, so that its outcome is comparable with that arm's.
   - **Forward:** another base's *abstained* row goes into the pair's *abstained* row. The outcome is the gold rate.
   - **Reverse:** another base's *answered* row goes into the pair's *answered* row. The outcome is the abstain rate.
   - **Donor choice:** same task × hardness. Prefer the same gold city, then the nearest |M_commit|. Flag pairs where no same-city donor exists.
   - **Why the build is wrong here:** as built, the forward control patches an answered recipient and scores gold. That is near 1 by default and says nothing about release.
2. **F1 margin position (ruling on choice 12; overruled).** F1 answers begin with the name ("Sarah lives in Leeds."), so the first generated token is not the city.
   - Read M_city and M_commit at the teacher-forced position that **produces the first pool city in the model's own F1 output**.
   - Rows with no pool city in the output are n/a, and are counted.
   - This stays descriptive.
3. **Random-arm sign.** The proposal (§5) aligns r̂ to the whole donor difference Δ, as sign(r̂ᵀΔ). `rand_states` currently aligns to the arm's own displacement.
   - Pass Δ = h_donor − h_recipient for the sign. Keep the norm as the arm's ‖patch_X‖.
   - Add a unit test.

## Checked and correct

- `cell_delta`:
  - weights are the false-abstention counts per cell;
  - cells lacking a class are counted as no-overlap;
  - the < 50% fallback works;
  - the pooled within-cell SD of answered rows is computed for the standardised Δ_M;
  - the bootstrap fixes the coarse choice from the point estimate (`ds["coarse"]`), so replicates cannot switch cell definitions.
- `state()` follows §4.5:
  - **lower/higher:** the 95% CI excludes 0 and the point estimate is beyond ±δ;
  - **similar:** the 90% CI is inside ±δ;
  - **when δ_S is undefined (R_S undefined):** there is no "similar" state.
- Projector: Π = U(UᵀU)⁺Uᵀ, and P-perp = (I − Π)Δ.
- The S-joint population uses the same rows as M, minus S-invalid rows. Per §4.3 the joint comparison should use the same rows for both. Report n for each.
