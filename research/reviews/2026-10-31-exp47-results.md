## 3. Rulings

1. **B2 is read as computed, with a circularity caveat that the proposal did not state and that I own.** Rev 0 §7
   says the §44 class labels "are used only to split tables, never as inputs to B1–B3". That sentence is wrong as
   written: the entry filter (follows at 1 nat) *is* the §44 class rule, so every entered row is a §44
   `answer_production` row and §47 reads only that class. B2 therefore cannot find an evidence-use failure: a row on
   which the forced readout does not follow the evidence never enters. What B2 does add to §44 is layer resolution:
   on the 13 failures whose readout follows, the gold's value is carried at its own positions through layer 30, is
   read from there at layers 31–32, and the random-vector control never moves it, exactly as on the 13 successes.
   The §44 classification of these rows is confirmed mechanistically; it is not extended to a class that §44 did not
   find. The EXPERIMENTS text must say this in the results paragraph, not in a limits footnote.
2. **On the thesis question (Q18): §47 finds no evidence-use failure because the §44 rev 8 sample contained none to
   read.** §44's classes at 1 nat were refusal 11 / 0 / 3 and wrong 15 / 0 / 3 (answer-production / evidence-use /
   indeterminate); the only `evidence_use` rows are three successes with a near-zero readout difference (§2.5). On
   these extractive single-hop rows, every classifiable failure is an answer-production failure, and §47 shows the
   carriage behind that class is layer-for-layer the same as on successes. The distinction Q18 asks for is therefore
   not *established* by contrast (no second class exists here) but *documented*: on this population the failures
   are downstream of evidence availability. D-45 applies: document, do not invent a population that would supply the
   missing class.
3. **B1 "yes" is accepted but is weaker than §46's result and is reported as such.** T ≈ 1 at L0–21 is expected
   whenever the readout copies the span's value: a patched residual at the span positions below the layer at which
   P1 reads them is equivalent to the token substitution (k3 = 1.0 confirms). The non-trivial content is the reading
   depth (31–32) and the controls at 0; the sentence "§46's mid-stack carriage holds on natural rows" is true but the
   two tasks measure different hops (§2.2). No sentence may say the bridge "replicates L* 15".
4. **B3 and the induced abstentions stay descriptive**, as pre-registered (5 refusal rows). The two refuse → answer
   rows are reported with their texts and with the fact that the swap prompt itself does not produce the answer on
   either; no sentence about "the refusal decision" or a "gate" is allowed. The user may wish to note the direction
   for the thesis narrative: it is the only place in §44–§47 where an in-view refusal was turned into an answer by a
   content-bearing intervention, and it was turned into the *wrong* (substitute) answer.
5. **B4's S2 = §44 forward patch to 1e-5 is a pipeline validation**, not a result: the two code paths (§44's single
   position, §47's fork readout with the prefix cache) agree on 312 reads. Recorded as such.
6. **The §44 class sentence in rev 0 §7 is corrected by this review** (ruling 1); no proposal edit after the read.
7. **The non-entered rows are not read** beyond §2.5; "L* 18" for them is not a number to quote.
8. **Quote miss recorded**: the pod cost ≈ $0.33, inside the quote; the projection ($0.613) exceeded it because the
   rule projects the slowest smoke row over all rows. The quote was fine; the projection rule is conservative by
   design. No change.
9. **Cost line**: "≈ $0.33 (lifetime; billing record pending)" until the API posts; the Executor re-reads
   list-pod-billing once and amends the EXPERIMENTS line and STATE spend if the figure differs by more than $0.02.
10. **D-45 / D-56 stopping rule**: §47 closes the §44 bridge. No same-answer control (k2) is possible on natural rows
    (rev 1 ruling 7), no second population is sought to manufacture an evidence-use class, no probe arm.
