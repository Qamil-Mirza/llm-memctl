## Required fixes

1. **R4 must offer no "unknown" option (ruling on choice 9).**
   - At present `prompt_r4` still contains the Chain-of-Note sentence "Reply unknown only if the memory has nothing at all on the topic." Remove that sentence too.
   - Add a case-check asserting that `"unknown"` does not occur (case-insensitive) in any `prompt_r4`.
   - R4 is the Ling-style control. A remaining "unknown" option would leave it half-done.
2. **The calibration repair must match *Legible Failures*' formula.**
   - `lf_vector` returns α·(μ_ĉ − μ_e). *Legible Failures* §5.1 uses α·‖h‖·unit(μ_ĉ − μ_e).
   - Use the paper's form, so that the F1 arm is a replication and not a variant.
   - The α_LF grid {0.5, 1, 2} and its objective (choice 7) stand.
3. **The design guard must check the commit itself.**
   - At present `require_design` checks only that the marker names *a* commit and that the marker's sha equals `design.json`.
   - Add these checks:
     - (a) `git cat-file -e <commit>` succeeds;
     - (b) `git show <commit>:runs/exp49/design.json` hashes, through `design_sha`, to the marker's sha;
     - (c) the working-tree `design.json` equals that blob.
   - Add a test with a fake repository, or monkeypatched git calls, covering a mismatch.
4. **Utility of degenerate outputs (ruling on choice 6).**
   - Count degenerate outputs as **0** in U, as §40 and §42 did ("0 for a refusal, degenerate output or soft refusal").
   - Leave degenerate out of `UNSUPPORTED` in the α objective.
   - Report the degenerate rate for every arm and set beside every rate.
   - Turning "unknown" into a broken string is a cost, but not an unsupported claim. This keeps U comparable with §40 and §42.
